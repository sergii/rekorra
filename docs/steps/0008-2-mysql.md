# Step 0008.2 - Real MySQL 8.4 host compatibility

Status: CI green on PR #20 ([CI run 40676233797](https://github.com/sergii/rekorra/actions/runs/40676233797)); main branch post-merge validation remains separate.

## Goal

Verify the entire Rekorra test-host integration against real MySQL 8.4, not only SQLite or PostgreSQL: migrations, tenant-isolated CRUD, CSRF and field policy checks, PaperTrail JSON, Access Audit, typed forms and enums, bounded association lookup, Sidekiq/Solid Queue, and 50,000-row offset/keyset pagination.

## Approach

- Dedicated MySQL 8.4 service and Rails 8.1 / Ruby 3.4 integration job with Redis.
- Set REKORRA_TEST_DATABASE_URL to a MySQL URL and assert the primary ActiveRecord adapter is Mysql2; leave Solid Queue on SQLite.
- Install mysql2 only in the test host. Never make it a Rekorra gem runtime dependency.
- Make SQL instrumentation recognize backtick-quoted identifiers; do not weaken limits on SQL count, cursor validation or tenant scoping.
